# НМТ-качалка укр_мови — Telegram-бот

Бот з інтервальним повторенням тем НМТ з української мови (структура й тексти — як в оригінальному боті @ukr_movych).

**Відмінності від оригіналу:**
- ⚡️ Кнопки реагують миттєво: відповідь на натискання відправляється паралельно з оновленням екрана, а посилання (тести, матеріали, підписка) відкриваються напряму, без запиту до бота.
- 🪄 Нові екрани з'являються **на місці попереднього** (повідомлення редагується), а не видаляються й надсилаються наново. У чаті завжди одне «живе» меню, яке зручно закріпити.
- ↩️ На кожному екрані є «Назад».

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # встав BOT_TOKEN та посилання
python -m bot
```

## Що де лежить

| Файл | Що там |
|---|---|
| `bot/texts.py` | **Усі тексти та список тем.** Тут додаються правила (`material`), посилання на матеріали (`material_url`) і тести (`test_url`) для кожної теми |
| `bot/keyboards.py` | Кнопки |
| `bot/handlers.py` | Логіка екранів |
| `bot/reminders.py` | Розсилка нагадувань про повторення |
| `bot/db.py` | SQLite-база (користувачі, відкриті теми, графік повторень) |
| `.env` | Токен, посилання, id закритого каналу, URL «Тренажерів» |

## Як працює

- `/start` → привітання → «👀 Зазирнути в бота й вчитися!» → опис бота → «🗺 Навігація» → меню.
- **Інтервальне повторення**: обираєш тему → бот запускає повторення й нагадує через 1, 3, 7, 14, 30 днів (змінюється в `REVIEW_INTERVALS_DAYS` у `bot/config.py`).
- **Базовий режим**: 1 нова тема раз на 10 днів (`FREE_UNLOCK_DAYS`). Учасники закритого каналу (`PREMIUM_CHANNEL_ID`, бот має бути адміном каналу) отримують усі теми одразу.
- **Повторювати своє**: користувач додає власні теми, бот нагадує про них за тим самим графіком.
- **Тренажери** (синя кнопка біля поля вводу): якщо вказати `TRAINERS_URL`, бот сам налаштує кнопку меню як Web App.

## Розгортання на безкоштовному сервері Google Cloud

1. Відкрий [Google Cloud Shell](https://shell.cloud.google.com/?show=terminal).
2. Встав команду й натисни Enter, далі встав токен бота:
   ```bash
   bash <(curl -fsSL https://raw.githubusercontent.com/ukrmovych/ukrmovych_bot/master/deploy/gcloud-create.sh)
   ```

Скрипт створює сервер `e2-micro` у `us-central1` (безкоштовний тариф), встановлює бота як сервіс і вмикає автооновлення: **кожні 5 хвилин сервер підтягує новий код з гілки `master`** і перезапускає бота. Тобто щоб оновити бота — достатньо запушити зміни.

Подивитися логи бота (у Cloud Shell):
```bash
gcloud compute ssh ukrmovych-bot --zone us-central1-a --command "sudo journalctl -u ukrmovych-bot -n 50 --no-pager"
```
Змінити токен — просто запусти команду з п. 2 ще раз.
