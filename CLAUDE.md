# Telegram-бот «НМТ-качалка укр_мовича» — пам'ятка для Claude

Власник — учитель української, не програміст. Усе робить Claude: пояснюй простою мовою, без жаргону, відповідай українською.
Власник хоче мати змогу сам відновити бота навіть без підписки на Claude — інструкції в `README.md` мають лишатися простими й актуальними.

## Що це
Бот для підготовки до НМТ з української з інтервальним повторенням тем (нагадування через 1, 3, 7, 14, 30 днів).
Робочий бот — @ukr_movych_bot (не тестовий @ukrmovych_test_bot). Його синя кнопка «Тренажери» відкриває ігри з ukrmovych/naholosy.
Очікується кілька тисяч учнів.

## Структура (Python, aiogram 3, SQLite)
- `bot/texts.py` — **усі тексти й список тем** (правила, посилання на матеріали й тести). Більшість змін — тут.
- `bot/handlers.py` — логіка екранів; `bot/keyboards.py` — кнопки.
- `bot/reminders.py` — розсилка нагадувань; `bot/db.py` — база SQLite.
- `bot/config.py` — налаштування з `.env` (`REVIEW_INTERVALS_DAYS`, `FREE_UNLOCK_DAYS` тощо).
- `.env` (немає в репозиторії; зразок — `.env.example`) — токен, посилання, id закритого каналу.
- `deploy/` — створення сервера й служби systemd.

## Як оновлюється
Сервер (Google Cloud, `e2-micro`, служба `ukrmovych-bot`) кожні 5 хвилин перевіряє гілку **`master`** і, якщо є новий код, сам оновлюється й перезапускає бота (`deploy/update.sh`). Тобто push у `master` = оновлення бота протягом 5 хвилин.

## Правила роботи
- Push у `master` одразу потрапляє до учнів — перед push перевір, що код запускається (`python -m py_compile bot/*.py`).
- Токен бота й інші секрети — лише в `.env` на сервері, ніколи в репозиторії (він публічний).
- Нова залежність — додай у `requirements.txt`, сервер встановить її сам.
- Не змінюй структуру таблиць у `db.py` без міграції: у базі вже є дані учнів.
